# RenameGuard

RenameGuardは、Windows上で複数ファイルの名前をまとめて変更するデスクトップアプリです。ファイルやフォルダーを追加すると変更後の名前をプレビューし、一覧のチェックを外したファイルは処理から除外できます。フォルダー追加では、その直下にあるファイルだけを読み込みます。

## インストール

- `RenameGuard-Setup-1.0.0-x64.exe`を実行し、インストール先を選びます。既定の保存先は`%LOCALAPPDATA%\Programs\RenameGuard`です。
- スタートメニューのショートカットを作成できます。デスクトップのショートカットは任意です。
- インストールはユーザー単位で行い、管理者権限は必要ありません。Windowsの「インストールされているアプリ」にRenameGuardとして登録されます。
- アンインストール時に設定と履歴を削除するか確認します。「いいえ」を選ぶとユーザーデータを保持します。

## 動作環境

- Windows 10 22H2 x64、またはWindows 11 x64
- .NET Framework 4.8以降

RenameGuardは通信、テレメトリ、クラウド保存を行いません。設定とUndo履歴は`%LOCALAPPDATA%\RenameGuard`に保存します。履歴の既定上限は50件で、10〜200件に変更できます。

## 使い方

1. 「ファイル追加」「フォルダー追加」、またはドラッグ＆ドロップで対象を追加します。
2. ルールを必要に応じて設定します。チェックされた処理は、前後空白の除去、リテラル文字置換、接頭辞、接尾辞、連番の順に適用されます。拡張子は常に保持されます。
3. プレビューとエラーを確認し、「名前を変更」を選びます。事前検証に失敗したファイルが一件でもあれば、全ファイルを変更しません。
4. 直近の変更は「直近をUndo」で元に戻せます。Undoも全件の事前検証を行います。

名前変更は同じフォルダー内の一時名を介した2段階処理です。実行に失敗すると元の名前への復元を試み、復元に失敗した場合は画面に対象パスを表示します。

## 配布物

- `RenameGuard-Setup-1.0.0-x64.exe`: ユーザー単位セットアップ
- `RenameGuard-Portable-1.0.0-x64.zip`: 展開して`RenameGuard.exe`を起動するポータブル版
- `SHA256SUMS.txt`: 配布ファイルのSHA-256

## 仕様上の差分

当初計画の.NET 8自己完結win-x64とInno Setupは、実行環境にSDK/コンパイラー/Inno Setupがなく、公式サーバーへのコマンドライン接続もTLS認証で失敗したため生成できませんでした。代替として、Windowsに付属する.NET Framework 4.8を対象にしたx64 WPFアプリと、アプリ一式をZIPで内包するユーザー単位セットアップを作成しています。対象Windowsに.NET Framework 4.8以降が必要なため、自己完結配布ではありません。セットアップ実行ファイルもコード署名されていません。

## ビルドとテスト

Windowsの.NET Framework 4.x C#コンパイラーを使って`Build.ps1`を実行します。NuGetや外部のUIライブラリーに依存しません。`RenameGuard.Tests`は依存なしのテストハーネスで、変換順序と拡張子保持、ケース設定、変更先衝突、全件事前検証、二段階交換、実行失敗時の復元、履歴保存、Undo競合、破損履歴退避、設定保存、1,000ファイルの一括変更とUndoを確認します。
